# Offline editorial illustrations

These two original illustrations were created for the project using the built-in
imagegen tool, then proportionally resized and encoded as WebP. They are generic
synthetic visuals, not actual clients, event footage or screenshots of a product.
The runtime reads these files locally and makes no image-generation API call.
Selection vocabulary, descriptions, provenance and SHA-256 are in
`../../skills/visual_library.json`. Uploaded project images have priority.

## Generation prompts

Make a finished illustration suitable as full-screen b-roll, not a multi-panel sheet.
